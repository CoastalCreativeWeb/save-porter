# Changelog

## v1.0 (2026-09-28)

First release.

- Copy saves between RetroBat, ArkOS handhelds (R36S etc.) and Android phones
- Box art, newer / older detection, one click to send a save across
- PS1 memory cards convert between DuckStation and RetroArch automatically
- GameCube, PS2, PSP, PS3 and Xbox 360 saves recognised, with real game names
- Phone support for RetroArch, Lemuroid, DuckStation, NetherSX2 / AetherSX2, Dolphin and PPSSPP over USB file transfer, USB ADB or Wi-Fi
- Never deletes anything, replaced saves are backed up first
